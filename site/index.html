From ticket to merge

Every ticket walks the same trail.

A ticket in cairn is a chantier: the ticket, its git worktree, its herdr workspace, its agents, its plan file and its pull request. Two decisions on the way are yours, and cairn puts them in front of you.

  1. Plan Your call

    p creates the worktree and the herdr workspace, starts the agent and asks for a plan sized to the ticket, side effects included. The agent stops. You answer its questions and approve with v.

  2. Build

    Tasks move as the agent works, with proofs: the commands it really ran, their results, the date. What is done folds away.

  3. Review Your call

    Nothing leaves without your go-ahead: a shows the commits and the side effects still open, then allows that commit. From there, CI, review and conflicts sit on one checklist.

  4. Shipped

    Merged on GitHub: cairn removes the worktree and the herdr workspace and archives the plan. Only when nothing can be lost: no uncommitted change, no commit missing from GitHub, no agent at work.

Nothing ships without you

A human go-ahead before the first push.

This is enforced, not only requested. A Claude Code hook blocks git push and gh pr create on a chantier's branch until you allow the commit you reviewed. Once the PR is open, fixes go through freely. Merging stays yours.

$ git push -u origin adrien/eng-412-rate-limit
cairn: ENG-412 needs a human approval before any push or PR.
Do not work around this block. Finish what you are doing,
set `attente: Prêt à pousser` in ~/.cairn/chantiers/ENG-412.md
with one line on what will ship, run `cairn sync`, then stop:
the human reviews in cairn and allows the push.

Get started

Your first chantier in three steps.

You need Go, gh logged in (gh auth login) and herdr.

  1. Install

    git clone https://github.com/Gradrien/cairn
cd cairn && ./install.sh --herdr

    The binary, the agents' skill, the push hook, and the cairn button in herdr's sidebar.

  2. Add a repository

    cd ~/code/eido && cairn add
cairn add --tracker linear --key ENG

    With no option, no tracker. Change anything later in the settings (s).

  3. Plan a ticket

    Open cairn from herdr (prefix a), press n, type a title or a number, then Enter. The plan comes in and waits for your go-ahead.
